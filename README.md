# Welcome to Fall 2026 QBIO 490 -- Directed Research: Multi-Omic Data Analysis!

Transitioning from traditional courses to a research lab can be challenging, as many critical scientific skills are not taught in the classroom setting. QBIO 490: Multi-Omic Data Analysis was developed to ease this transition in a low-stakes supportive environment and to also facilitate a stronger community among QBIO students. We hope this course will provide you all with opportunities to learn and grow as students and as researchers!

# Required Texts and Equipment
There are no required textbooks for this course. The only equipment required is a laptop that you must bring to class each day.
